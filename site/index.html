A music player for the terminal that keeps playing after you detach.

Playback runs in a background server. Open the interface, pick a track, press q to close it, and reattach from any pane later.

Plays local files and live radio from one shared queue, with a JSON CLI and event stream for scripts and agents.

We loved the little player that lived on our desktop. These days, we live in a terminal. The music should feel at home here, too.

Album covers come through in high resolution with Sixel or Kitty graphics, automatically detected when you attach. Ghostty + tmux uses Kitty; Sixel in tmux requires support from both tmux and the outer terminal. Color halfblocks keep the artwork visible when pixel graphics aren’t available.

TUIPLAYBACK SERVERCLI / AGENTS

One shared queue. As many interfaces as you need.

Listen from another machine.

A server can run without an audio device and send what it plays as an Ogg Opus stream instead. Start it with --headless on the machine that holds the music, a Mac or a Linux box. The queue, the library, and the CLI work as before, and a server that plays through its own speakers can cast as well with --cast.

Listen with mpv or ffmpeg over SSH, open the stream in a player with --cast-http, or start a local vtamp with --remote: it plays the remote server through your speakers and shows its queue in the TUI.

Read about the headless server 
# On the machine with the music, macOS or Linux
vtamp server start --headless

# From any machine with mpv
ssh music-box vtamp cast listen | mpv -

# Or a local vtamp, after forwarding the socket over SSH
vtamp server start --remote /tmp/music-box.sock

Ogg Opus · 48 kHz stereo · 128 kbit/s · Each track start, seek, and resume begins a new logical stream.

Meet the macOS controls

Now playing, in your tmux bar.

Close the player and keep the current track in sight. The optional tmux plugin shows the song title and elapsed / total time, right in your status bar.

Pause and the track stays visible. Stop playback or shut down the server and it disappears. Choose the width, add the artist, and place it wherever you like.

Set up the tmux plugin

Put #{vtamp} in your status format before loading the plugin. No clock or date required.

set -g status-right \
  '"#{=21:pane_title}" #{vtamp}'
TPM or direct loading

A spectrum in fourteen styles.

Press v to show a read-only spectrum of what the server is playing, and V to switch between fourteen styles: bars, gradient, mono, mirror, dots, waterfall, radial, fire, ridge, sparks, squares, smooth, trail, and stereo.

Every style takes its colors from your theme. Audio is analyzed only while the spectrum is shown; when playback pauses or stops, it settles and stops redrawing.

HOMEBREW · APPLE SILICON

One command, no Rust toolchain. Then register a folder and attach:

# Install the player
brew install rath/tap/vtamp

# Register your music folder
vtamp library add ~/Music

# Attach. Pick a track. Press Enter.
vtamp

No permanent pane required. q to detach.

BUILD FROM SOURCE

Intel Mac, or no Homebrew? With Rust 1.90 or newer and cmake installed, clone the repository and install. On Linux the same commands build a headless server, or download the aarch64 build from the latest release.

# Get the source
git clone https://github.com/rath/vtamp.git
cd vtamp

# Install the player
cargo install --locked --path .
vtamp
