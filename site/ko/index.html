화면을 닫아도 재생이 멈추지 않는 터미널 음악 플레이어.

재생은 백그라운드 서버가 맡습니다. 플레이어를 열어 곡을 고르고 q로 닫은 뒤, 나중에 다른 창에서 다시 열어도 그대로 이어집니다.

로컬 파일과 라이브 라디오를 하나의 큐에서 재생합니다. 스크립트와 에이전트를 위한 JSON CLI와 이벤트 스트림도 제공합니다.

데스크톱 한구석에 두고 쓰던 작은 플레이어를 좋아했습니다. 요즘은 하루 대부분을 터미널에서 보내니, 음악도 여기에 있는 편이 자연스럽습니다.

앨범 커버는 Sixel 또는 Kitty 그래픽으로 고해상도 표시되며, 접속할 때 자동으로 감지합니다. Ghostty + tmux는 Kitty를 사용하고, tmux에서 Sixel을 쓰려면 tmux와 바깥 터미널이 모두 지원해야 합니다. 픽셀 그래픽을 쓸 수 없으면 컬러 하프블록으로 커버를 보여 줍니다.

색 테마는 아홉 가지입니다. 기본값인 Catppuccin Mocha, 밝은 Latte, Rosé Pine, 초기 녹색 Classic 등이 있습니다. t로 미리 보고 Enter로 저장하면 다음 접속부터 적용됩니다.

$ vtamp

$ vtamp

다른 기기에서 듣기

서버는 오디오 장치 없이 실행하면서 재생하는 소리를 Ogg Opus 스트림으로 내보낼 수 있습니다. 음악 파일이 있는 Mac이나 Linux 기기에서 --headless로 시작하면 큐, 라이브러리, CLI는 그대로 동작합니다. 스피커로 재생하는 서버도 --cast를 붙이면 같은 스트림을 내보냅니다.

SSH 너머에서 mpv나 ffmpeg로 듣거나, --cast-http로 플레이어에서 URL을 열거나, 로컬 vtamp를 --remote로 시작할 수 있습니다. 로컬 vtamp는 원격 서버의 큐를 TUI에 보여 주고 소리는 내 스피커로 재생합니다.

헤드리스 서버 설명 보기 
# 음악이 있는 기기, macOS 또는 Linux
vtamp server start --headless

# mpv가 있는 아무 기기에서
ssh music-box vtamp cast listen | mpv -

# 또는 SSH로 소켓을 포워딩한 뒤 로컬 vtamp로
vtamp server start --remote /tmp/music-box.sock

Ogg Opus · 48 kHz 스테레오 · 128 kbit/s · 곡 시작, 탐색, 재개마다 새 논리 스트림이 시작됩니다.

미디어 키와 Now Playing 지원

익숙한 미디어 키를 그대로 씁니다. 플레이어를 닫아 둔 채로, tmux에서 detach한 뒤에도 재생, 일시정지, 곡 넘기기가 됩니다.

곡 제목, 아티스트, 앨범 커버가 macOS Now Playing에 표시됩니다. 터미널을 열지 않아도 제어 센터에서 바로 조작할 수 있습니다.

tmux 상태 표시줄에 현재 곡 표시

플레이어를 닫아도 현재 곡을 계속 볼 수 있습니다. 선택 설치하는 tmux 플러그인이 곡 제목과 경과 / 전체 시간을 상태 표시줄에 보여 줍니다.

일시정지해도 곡은 계속 표시되고, 재생을 멈추거나 서버를 끄면 사라집니다. 너비를 정하고, 아티스트를 추가하고, 원하는 위치에 둘 수 있습니다.

tmux 플러그인 설치하기

플러그인을 불러오기 전에 상태 형식에 #{vtamp}를 넣어 두세요. 시계나 날짜는 없어도 됩니다.

set -g status-right \
  '"#{=21:pane_title}" #{vtamp}'
TPM 또는 직접 불러오기

14가지 스타일의 스펙트럼

v를 누르면 서버가 재생 중인 음악의 스펙트럼이 열립니다. 읽기 전용이며, V를 누를 때마다 bars, gradient, mono, mirror, dots, waterfall, radial, fire, ridge, sparks, squares, smooth, trail, stereo 순서로 스타일이 바뀝니다.

모든 스타일은 테마 색을 그대로 씁니다. 오디오 분석은 스펙트럼이 보이는 동안에만 돌고, 재생을 일시정지하거나 멈추면 스펙트럼이 가라앉은 뒤 화면 갱신도 멈춥니다.

명령 하나면 되고 Rust 툴체인은 필요 없습니다. 설치한 뒤 음악 폴더를 등록하고 접속하세요:

# 플레이어 설치
brew install rath/tap/vtamp

# 음악 폴더 등록
vtamp library add ~/Music

# 접속. 곡을 고르고 Enter.
vtamp

창을 계속 띄워 둘 필요가 없습니다. q로 닫습니다.

소스에서 빌드

Intel Mac이거나 Homebrew가 없다면 Rust 1.90 이상과 cmake를 설치한 뒤 저장소를 복제해 설치하세요. Linux에서는 같은 명령으로 헤드리스 서버가 빌드되고, 최신 릴리스에서 aarch64 빌드를 내려받을 수도 있습니다.

# 소스 받기
git clone https://github.com/rath/vtamp.git
cd vtamp

# 플레이어 설치
cargo install --locked --path .
vtamp
